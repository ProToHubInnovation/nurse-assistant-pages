ข้อมูลส่วนตัว (Profile)

ข้อมูลประจำตัวและตำแหน่งสำหรับการใช้สิทธิ์จองวันหยุด

เจ้าหน้าที่

เลขที่เงินเดือน: -
ผู้ช่วย (Assistant)
ความปลอดภัย (Security)
รหัส PIN ประจำตัว
สิทธิ์โควตาประจำตำแหน่ง
3 คน / วัน (โควตารวมพยาบาลและผู้ช่วย)
กฎระเบียบการจองสำหรับตำแหน่งของคุณ:
  • โควตารวมต่อวันคือ 3 คน สำหรับพยาบาลและผู้ช่วย โดยนับ OFF และ Vacation รวมกัน
  • การจอง OFF และ พักร้อน (Vacation) นับรวมกันในโควตาเดียวกัน
  • จองสำเร็จแล้วมีผลทันทีโดยไม่ต้องรอขั้นตอนอนุมัติ
  • รหัส PIN ใช้เพื่อยืนยันตัวตน ป้องกันการจองหรือยกเลิกสลับกัน
